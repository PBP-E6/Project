# Website tracker carbon footprint dari makanan

Web application untuk tracking carbon footprint dari makanan yang kita konsumsi sehari-hari..

## Peran pengguna

Pengguna dapat:
- meng-explore makanan dengan emisi datanya
- Search, filter, dan mengkomparasikan makanan
- Track daily food intake dan track total emisi
- login untuk menyimpan history/tracking-nya
